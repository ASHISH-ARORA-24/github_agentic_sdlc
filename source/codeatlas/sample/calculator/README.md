# calculator

A simple Python script with three arithmetic functions.

This repo exists as a sample codebase for testing CodeAtlas. It is intentionally small and well-documented so we can verify that indexing, embedding, and question answering are working correctly before moving to more complex codebases.

## Functions

- `add(a, b)` — returns the sum of two numbers
- `subtract(a, b)` — returns the difference of two numbers
- `multiply(a, b)` — returns the product of two numbers
